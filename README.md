# 🎮 Jogo de Tabuada

Um jogo interativo desenvolvido para praticar e testar conhecimentos de multiplicação de forma simples e divertida!

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos em Desenvolvimento de Sistemas, com o objetivo de praticar lógica de programação e desenvolvimento web.

## 💡 Funcionalidades

- Prática de operações de multiplicação.
- Interação com o usuário.
- Interface simples e intuitiva.
